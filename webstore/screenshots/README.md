# Chrome Web Store screenshots

Keep screenshots flat in this directory and use filename prefixes:

- `global1.jpg`: no locale-specific text; reusable for all listings
- `en1.jpg`: English UI
- `zh_CN1.jpg`: Simplified Chinese UI
- `ja1.jpg`: Japanese UI

Do not create locale subdirectories. Screenshots should be JPEG or 24-bit PNG without alpha, preferably 1280×800 or 640×400.
